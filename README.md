Entry for the [make.fun bounty "The Most Boring Object, Reviewed in One Line"](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3): one line of at most 200 characters — a funny, true review of the dullest everyday object, the doorstop.

## The entry

> The doorstop: six years holding this door open, zero thank-yous, and the door still gets all the credit for being so welcoming.

(127 characters, one line.)

## Run it

```sh
python3 main.py
```

`main.py` writes the entry line to `/output/entry.txt` (or `$ENTRY_OUTPUT`)
and includes a `validate_entry` gate check plus a `--self-test` enforcing
the 1–200 character, single-line, no leading/trailing whitespace rule.
The output is deterministic — byte-identical on every run.
